1. Executive Overview & Philosophy

FocusDesk is a modern, production-grade productivity and deep-work companion engineered with Kotlin Multiplatform (KMP), Jetpack Compose, and Room Database. It departs from conventional Pomodoro apps by eliminating static asset loops and third-party UI widgets in favor of native platform integration:

  • System-Native Dynamic Island: Pins an active foreground MediaSession with Notification.MediaStyle to project live countdowns directly into the camera punch-hole island and status bar on modern Android devices (ColorOS/OxygenOS Aqua Dynamics, Xiaomi HyperOS, Samsung One UI, and Android 14/15 Live Notifications).
  • Procedural Ambient Audio Synthesizer: Rather than bundling 60MB of pre-recorded audio files that suffer from audible loop seams, FocusDesk synthesizes stereo rain, Brownian noise, pink noise, coffee shop rumble, and forest birdsong mathematically at 44,100 Hz in real-time.
  • Offline-First Room Persistence: All focus sessions, user settings, streak counters, and task priorities are saved locally in an embedded SQLite Room database with reactive Kotlin Flow queries and automatic schema seeding.
  • Tactile Spring Physics Design System: Bespoke glassmorphism, 5 curated theme palettes, and spring curves calibrated 1:1 against Apple SwiftUI .snappy, .smooth, and .bouncy physics.

2.1 Key Design Questions Answered

Design Decision Why It Is Structured This Way
Why is FocusRepository in shared while RoomFocusRepository is in composeApp? Adheres to Clean Architecture's Dependency Inversion. The Domain layer defines the business contract (FocusRepository). The concrete implementation depends on Android SQLite Room APIs, which belong in the Android-specific composeApp module.
Why use expect/actual for Audio and Haptics? Audio output (AudioTrack on Android vs AVAudioEngine on iOS) and Haptics (VibratorManager on Android vs UIFeedbackGenerator on iOS) require low-level platform APIs. Declaring expect class AmbientAudioEngine allows the shared Domain layer to trigger audio without caring what OS is underneath.
Why separate presentation/ subfolders by feature instead of by layer? Feature-First Packaging ensures high cohesion. All components relating to the timer (TimerScreen, TimerViewModel, TimerContract, ActiveFocusSessionCard) live together in presentation/timer/, making navigation and code review immediate.

3. Architecture Paradigm: Clean Architecture + MVI

FocusDesk implements a strict Model-View-Intent (MVI) pattern powered by Kotlin Coroutines and StateFlow. All ViewModels inherit from the base MviViewModel<I, S, E>:

User Action (Click / Drag) │ ▼ 1. Dispatch MviIntent (e.g. TimerIntent.ToggleTimer) │ ▼ 2. handleIntent(intent) in ViewModel │ ├─────────────────────────────────┐ ▼ ▼ 3. Execute UseCase 4. Pure Reducer setState { ... } (TimerEngineUseCase.startTimer()) (MutableStateFlow.update) │ │ ▼ ▼ 5. Repository updates Room DB 6. UI observes StateFlow (RoomFocusRepository) (collectAsStateWithLifecycle()) │ │ ▼ ▼ 7. Foreground Service Sync 8. Compose Recomposes Atomically (DynamicIslandService updates chip) (Canvas, Buttons, Text) │ ▼ 9. One-Shot Effect Dispatched via Channel (_effects.send(TimerEffect.PlayTickHaptic))

3.1 The MVI Contract Classes

  • MviState: Marker interface. Each screen has exactly one immutable data class representing 100% of its visual state (e.g. TimerState, SettingsState, AnalyticsState).
  • MviIntent: Marker interface representing all possible user or system intentions (e.g. TimerIntent.ToggleTimer, TimerIntent.AddFiveMinutes, TimerIntent.ConfirmReset).
  • MviEffect: Marker interface for one-off transient events consumed once by the UI (e.g. ShowSnackbar, PlayCelebrationHaptic, PlaySoundEffect). Backed by a buffered coroutine Channel to guarantee zero dropped events during screen rotations.

5.2 Streak & XP Gamification Algorithm (RoomFocusRepository.kt)

When a focus session is recorded as completed, RoomFocusRepository executes an atomic transaction: 

val nowMs = System.currentTimeMillis()
val currentEpochDay = nowMs / (1000L * 60 * 60 * 24)

val newStreak = when {
    settings.lastActiveEpochDay == currentEpochDay -> settings.dayStreak.coerceAtLeast(1)
    settings.lastActiveEpochDay == currentEpochDay - 1 -> settings.dayStreak + 1
    else -> 1 // Gap detected: streak broken, reset to day 1
}
val bestStreak = maxOf(settings.bestStreak, newStreak)
val sessionMinutes = ((session.targetDurationSeconds - session.remainingSeconds).coerceAtLeast(60L) / 60).toInt()
val pointsEarned = maxOf(sessionMinutes, 6) // Base XP + duration bonus
val newXp = settings.xp + pointsEarned
val newLevel = (newXp / 100) + 1

userSettingsDao.updateXpAndStreak(newXp, newLevel, newStreak, bestStreak, currentEpochDay)

5.3 Weekly 7-Day Bucket Distribution Algorithm

observeProductivityStats() uses Kotlin Coroutines combine() across sessions, tasks, and settings to build the 7-day Monday-to-Sunday bar chart in real-time:

  • Calculates Monday 00:00:00 timestamp using Calendar.getInstance().apply { firstDayOfWeek = Calendar.MONDAY }.
  • Allocates 7 buckets: [0 = Monday, 1 = Tuesday, 2 = Wednesday, 3 = Thursday, 4 = Friday, 5 = Saturday, 6 = Sunday].
  • Iterates through sessions completed this week and accumulates focusMinutes and sessionsCount into the matching bucket.

6. Hardware, Sound Synthesis & System Services Deep Dive

6.1 Procedural Ambient Audio Synthesizer (AmbientAudioEngine)

Located in shared/src/androidMain/kotlin/com/focusdesk/core/platform/AndroidAudioPlayer.kt.

Why Procedural Synthesis? Pre-recorded audio files consume 60+ MB of storage and suffer from audible loop seams. FocusDesk calculates audio samples mathematically in real-time at 44.1 kHz 16-bit PCM, producing seamless infinite soundscapes with a 0 MB bundle size.
Soundscape Synthesis Mathematical Model & Implementation Details
Rain & Heavy Rain 1st-order IIR low-pass filtered white noise (filterState = filterState * 0.94 + white * intensity). A Poisson-distributed random drop generator inserts micro-sine bursts with randomized pitch (1,000–3,000 Hz) with exponential amplitude decay.
White, Pink, Brown Noise Gaussian random walk generator (random.nextGaussian() * 0.35). Filter coefficients dictate the frequency slope: BrownNoise = 0.96 (-6 dB/octave warm deep rumble), PinkNoise = 0.92 (-3 dB/octave equal energy per octave), WhiteNoise = 0.86 (crisp uniform energy).
Coffee Shop & Library Dual low-frequency sinusoidal fundamentals at 65 Hz and 130 Hz simulate HVAC ventilation and background refrigerator hums, blended with stochastic filtered chatter noise.
Forest & Birdsong 0.25 Hz sine envelope modulates background wind turbulence. A periodic 3-second cycle triggers multi-tone bird chirps peaking at 2,400 Hz with frequency modulation.
Ocean 0.10 Hz sinusoidal swell envelope modulates filtered surf noise, simulating rhythmic crashing ocean waves on a shoreline.

6.2 Dynamic Island & Foreground Service (DynamicIslandService)

Located in composeApp/src/main/kotlin/com/focusdesk/app/service/DynamicIslandService.kt.

9.1 How to Add a New Soundscape in 3 Steps

  1. Open UserSettings.kt and add the enum entry: Campfire("Campfire", isPremium = false, category = "Nature").
  2. Open AndroidAudioPlayer.kt and implement the synthesis formula inside the when (currentSoundscape) loop.
  3. Finished! The soundscape immediately appears on the Sounds screen, bottom sheet, and quick-start cards.

9.2 Common Gotchas & Solutions

Gotcha 1: Concurrency & Fast Ticking
Never bypass the 850ms guard in TimerEngineUseCase.tick(). Multiple coroutines (ViewModel and Foreground Service) observe the session; without this guard, the timer could run at double speed.
Gotcha 2: AudioTrack Main Thread Blocking
Never write audio samples to AudioTrack on the Android UI Main thread. Audio generation must always occur on the dedicated background daemon thread (FocusDesk-AudioSynth).
Gotcha 3: Jetpack Compose State Lifecycles
Always use collectAsStateWithLifecycle() instead of collectAsState() to ensure Room database flows pause when the application is minimized, preserving battery life.
